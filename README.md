## Getting Started
1. Get 12.4.6.
2. Unpack the zip.
3. Run `Ableton12-Setup.exe`.
4. Pick Suite and Max for Live.
5. Set ASIO.
6. Notes in `files/notes/`.

## FAQ

**12.5?**
12.4.6 is the current stable pin. 12.4.15b is beta.

**Lite?**
This zip is Suite trial notes. Authorize from an Ableton account.
